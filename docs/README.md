# Betaflight Drone Documentation

This directory contains technical specifications, pinout diagrams, wiring tables, and troubleshooting guides for the STM32F411 Black Pill Betaflight drone project.

## Directory Contents

- **`images/`**: High-resolution screenshots of Betaflight Configurator (Setup tab, Configuration tab) and hardware pinout diagrams.
- **`engineering-qa-troubleshooting.md`**: Complete chronological Question & Answer engineering journey documenting every technical problem, root-cause diagnosis, and firmware patch from day one.
- **`master-hardware-guide.md`**: Complete, comprehensive handover documentation detailing every hardware component, electrical parameter, and timer calculation.
- **`setup-guide-bn.md`**: Step-by-step setup guide written in Bengali (বাংলা গাইড) for Bengali-speaking builders.
- **`wiring-guide.md`**: Complete pin-to-pin wiring reference for I2C sensors, receiver, GPS, and ESCs.
- **`troubleshooting.md`**: In-depth solutions for common Betaflight Black Pill issues (arm prevention flags, driver issues, I2C errors).
- **`instructions.md`**: Fast CLI loading steps.
- **`STM32F411CE-Black-Pill-Board-Pinout-Diagram.png`**: High-resolution pinout reference image of the STM32F411CEU6 Black Pill board.
