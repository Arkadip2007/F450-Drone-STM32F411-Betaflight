# Official Betaflight Releases

This directory stores upstream Betaflight release files for STM32F411 Black Pill:

- `betaflight_4.3.2_BLACKPILL_.hex`: Stable 4.3.2 release for Black Pill.
- `betaflight_4.5.1_STM32F411_STM32F411CEU6.hex`: Official 4.5.1 release for generic STM32F411CEU6 targets.
- `betaflight_4.3.2_BLACKPILLSD_SS1_Hexa-FIX.txt`: Hexacopter target configuration script.
- `betaflight_4.3.2_BLACKPILLSD_SS2_NoHexa-FIX.txt`: Quadcopter target configuration script.
